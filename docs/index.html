Key insight

Distance drives 78% of trip duration. Rush-hour status adds 16% — the same 3-mile trip takes 10 min at midnight and 21 min at 5 PM. A dispatcher using only distance would be systematically optimistic during peak hours.

End-to-end pipeline — tap any stage
💾
generate_sample.py
40K seeded synthetic trips + zone lookup
Generates 40,000 trips with seed=42. Embeds rush-hour signal (×1.9 for 7–10, ×2.1 for 16–19) and ~2% dirty rows.
Data
📋
ingestion.py
Typed-schema CSV → curated Parquet
Reads CSV with an explicit StructType. Supports real TLC Parquet via normalize_trips() for schema-drift tolerance. Writes data/curated/trips/.
Structured API
🔧
transformations.py
Clean + features + broadcast join + SQL
Removes bad rows. Derives pickup_hour, is_weekend, is_rush_hour. Broadcast-joins zone lookup. Queries demand-by-hour + top-10 zones via Spark SQL.

streaming.py
12 micro-batch simulation → aggregation
Splits sample into 12 CSVs. maxFilesPerTrigger=1, outputMode=complete, trigger(availableNow=True). Pure aggregation function testable on static data.
